# Contributing

Спасибо за интерес к проекту!

## Как предложить изменения

1. Создайте fork репозитория
2. Создайте ветку для ваших изменений: `git checkout -b feature/my-feature`
3. Закоммитьте изменения: `git commit -m 'Add some feature'`
4. Запушьте в ветку: `git push origin feature/my-feature`
5. Создайте Pull Request

## Стиль кода

- Используйте bash best practices
- Добавляйте комментарии для сложных моментов
- Тестируйте скрипты перед созданием PR

## Сообщения коммитов

Используйте понятные сообщения коммитов на русском или английском языке.
